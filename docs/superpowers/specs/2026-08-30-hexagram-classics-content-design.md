# 卦辞爻辞与原创白话设计规格

日期：2026-08-30

目标项目：`D:\HexaAgent-XHS`

## 1. 目标

补齐结果页“卦爻参考”内容，为六十四卦提供可离线读取的卦辞、六条爻辞、乾坤用九/用六及原创白话。内容用于帮助用户理解经典文本，不替代纳甲六爻综合判断，也不按爱情、事业、财运等现代类别硬编码吉凶。

## 2. 内容范围

每卦收录：

- 卦名和文王卦序。
- 卦辞原文与原创白话。
- 初、二、三、四、五、上六个爻位的爻辞原文与原创白话。
- 乾卦“用九”和坤卦“用六”原文与原创白话。

首版不收录《彖传》《象传》《文言传》《系辞传》等传文，不收录现代作者的爱情、事业、财运分类断语。

## 3. 内容原则

### 3.1 原文

- 以可靠的通行本《周易》经文为底本，至少对照两个可信来源校验卦名、卦辞和爻辞。
- 保留通行标点，异体字统一为简体常用字；不擅自改写经典语句。
- 对存在常见版本差异的字词，在资料说明中记录采用版本，不在移动端正文堆叠校勘信息。

### 3.2 原创白话

- 解释原文中的处境、动作、风险和提醒，语言简洁，适合手机阅读。
- 不复制现代书籍或网站译文，不模仿特定作者表达。
- 不把卦辞或爻辞直接改写成“一定成功”“必然分手”等确定性预测。
- 对古代制度、器物或习语只做理解所需的最小解释。
- 白话只解释经典文本；本次占问结论仍由离线初判引擎根据问题类别、用神、世应、旺衰和动变生成。

## 4. 数据结构

新增独立的经典文本模块，不把内容塞入六十四卦识别表：

```ts
interface ClassicPassage {
  original: string
  plain: string
}

interface ClassicLine extends ClassicPassage {
  position: 1 | 2 | 3 | 4 | 5 | 6
  label: string
}

interface HexagramClassicText {
  sequence: number
  name: string
  judgement: ClassicPassage
  lines: readonly [ClassicLine, ClassicLine, ClassicLine, ClassicLine, ClassicLine, ClassicLine]
  special: ({ kind: 'use-nine' | 'use-six'; label: string } & ClassicPassage) | null
}
```

模块通过现有引擎使用的标准卦名查找，提供：

- `getHexagramClassic(name)`：返回指定卦完整文本，找不到时返回 `null`。
- `getRelevantClassicLines(name, changingLines)`：按初爻到上爻顺序返回本次动爻文本。

数据全部打包到本地静态产物，不运行时请求网络，不动态下载内容。

## 5. 结果页展示

“卦爻参考”按照本次卦象逐层展示：

1. 本卦卦名、卦辞原文和白话始终显示。
2. 有动爻时，紧接着显示本卦对应动爻的爻辞原文和白话，并用朱砂色边线突出。
3. 无动爻时，不擅自选择某一条爻辞，只以卦辞作为主要经典参考。
4. “查看全部爻辞”折叠区列出本卦六条爻辞；乾坤特殊条目置于六爻之后。
5. 有变卦时，显示“变化后的整体意象”，包含变卦卦辞原文和白话；不把变卦爻辞当成本次动爻。
6. 保留提示：“卦辞爻辞反映经典文本的整体意象，不等同于六爻纳甲综合判断。”

原文和白话使用明确标签区分，避免用户误认为白话属于古典原文。

## 6. 异常处理

- 文本查找失败时保留当前卦宫、世应摘要，并显示“该卦经典文本暂缺”，结果页不得崩溃。
- 某条爻辞缺失时只隐藏缺失条目并显示数据提示，不用其他爻辞代替。
- 数据完整性测试应在构建前阻止缺卦、缺爻、重复卦序、名称不匹配或空白文本进入发布包，因此正常发布版本不应触发上述降级。

## 7. 测试策略

- 数据表恰好包含 64 卦，卦序为 1–64 且不重复。
- 所有名称与现有六十四卦识别表一一对应。
- 每卦都有非空卦辞原文、卦辞白话和六条按位置排序的爻辞。
- 乾卦只有用九，坤卦只有用六，其余卦没有特殊条目。
- 静卦只突出卦辞；一个或多个动爻按爻位显示对应本卦爻辞。
- 有变卦时显示变卦卦辞，不显示变卦动爻。
- 未知卦名触发安全降级。
- 全量测试、离线构建扫描和移动端结果页集成测试继续通过。

## 8. 验收标准

- 六十四卦卦辞、384 条常规爻辞、用九、用六均可离线查阅。
- 每段原文都有独立撰写的白话说明。
- 结果页优先展示本卦卦辞和实际动爻，长内容默认折叠。
- 页面不出现固定的爱情、事业、财运吉凶分类。
- 白话与古典原文视觉和语义边界清晰。
- 构建产物保持零外部请求、零违规能力。
