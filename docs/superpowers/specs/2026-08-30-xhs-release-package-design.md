# 小红书小工具发布包设计

## 目标

为“问爻”生成可直接上传小红书小工具后台的离线 ZIP、方形应用图标、上架简介和可复核的校验摘要。最终包必须符合工作区 `.codex/SKILL.md`（`minitool-zip-builder` 1.4.0）及其全部 references。

## 当前差异

现有 `dist` 已满足相对路径、单入口、零业务网络请求和移动端布局，但 Vite 输出仍使用 `type="module"`，并注入 module-preload polyfill；该 polyfill 含 `fetch`。官方规范要求经典外置脚本且禁止网络 API，因此当前 `dist` 不可直接上传。

## 发布流程

1. 保持 React、业务逻辑和界面不变，只调整生产构建链。
2. 关闭 Vite module-preload polyfill；构建完成后把唯一入口脚本转换为经典 `defer` 脚本。
3. 扩展静态扫描器，拒绝 `type="module"`、模块语法、官方能力清单中的禁用 API、绝对资源路径、外部资源、额外 HTML、非法扩展名和缺失资源。
4. 运行 Lint、145 个现有测试、生产构建、离线 E2E 和移动端 E2E；最终预览必须来自处理后的 `dist`，不能预览开发服务器后便直接打包。
5. 压缩 `dist` 的内容本身，使 `index.html` 位于 ZIP 根目录；解包复检文件类型、引用、入口和体积。
6. 上传 ZIP 到小红书 PC 模拟器预览，再按审核文档进行真机测试。平台模拟器/真机是本地测试之后的容器验收，不替代本地门禁。

## 构建与错误处理

- 新增确定性的产物后处理脚本：必须只找到一个模块入口；找不到或找到多个时立即失败，不猜测替换。
- 后处理后再次确认无 `type="module"`、`modulepreload`、`import`、`export`、`import.meta` 和真实 `fetch` 调用。
- React 生产包中的 `react.dev/errors` 仅是错误消息链接字符串，W3C SVG namespace 仅是 DOM 命名空间常量；二者不产生资源加载，扫描器保留精确豁免，其他 URL 继续拒绝。
- 不接入 JSBridge；当前发布范围不需要发笔记、存相册或跳原生页。
- ZIP 超过 10MB、根目录缺少 `index.html`、出现额外目录包裹或不支持扩展名时，打包失败且不交付。

## 图标与上架文案

图标输出 512×512 PNG：米白纸张质感底色、朱砂红抽象六爻符号、克制的方形印章构图，不使用照片、渐变霓虹或复杂小字；缩小后仍应能辨认。图标是后台上架素材，不放入运行 ZIP，避免无用体积。

上架名称使用“问爻”。简介采用：

> 离线六爻起卦与排盘记录工具，支持模拟摇卦、现实投币和手动排盘，提供卦爻原文、白话参考、卦例记录与 AI 提示词整理。数据仅保存在本机，不上传云端。内容仅供传统文化研究与娱乐参考。

## 产物

- `release/wenyao-xhs-0.1.0.zip`：上传包，`index.html` 位于根目录。
- `release/wenyao-icon-512.png`：后台图标。
- `release/release-summary.md`：名称、简介、构建时间、ZIP 大小、SHA-256、文件清单与逐项校验结果。

`release/` 产物不提交 Git；构建脚本、扫描规则、测试、官方 skill 和设计/实施文档提交 Git。

## 验收标准

- 官方 references 的所有适用检查项通过；无适用 JSBridge 调用。
- ZIP 小于 2MB 建议值；无论如何不得超过 10MB。
- 本地最终产物预览、零外部请求测试、320/375/430px 无横向溢出测试通过。
- ZIP 解包后与已验证 `dist` 文件逐项一致。
- 独立代码审查无 Critical 或 Important 问题。
