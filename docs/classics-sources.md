# 卦辞、爻辞来源与编辑说明

## 收录范围

本项目只收录《周易》经文中的 64 条卦辞、每卦六条常规爻辞，以及乾卦“用九”、坤卦“用六”。不收录《彖传》《象传》《文言传》《系辞传》等传文，也不把后世占断分类混入经文层。

## 原文底本与交叉核对

整理日期：2026-08-30。

1. [Chinese Text Project：《周易》](https://ctext.org/book-of-changes/zh)：其页面说明所据版本为阮元校刻《十三经注疏》本《周易正义》，用于确认篇目、经传边界和关键字形。
2. [Project Gutenberg: The Yî King, ebook 25501](https://www.gutenberg.org/ebooks/25501)：提供完整可检索纯文本，用于逐卦核对卦辞、六爻顺序和乾坤特殊条目。
3. [维基文库：《周易》](https://zh.wikisource.org/wiki/周易)：作为第二个在线逐章视图，复核标点断句与常见异文。

录入时曾使用开源结构化数据辅助机械分段，但不把它作为权威底本；例如该数据把乾卦九二误作“见龙再田”，项目已按上述底本校正为“见龙在田”。

## 字形、标点与异文原则

- 正文采用现代简体字与全角现代标点，保留“说”“有孚”“无咎”等经文用字，不把古义词改写进原文。
- 卦辞统一带短卦名开头，如“乾：”；爻辞的“初九”“六二”等标签单独存储，正文不重复标签。
- 对不影响字义的标点差异，以便于移动端阅读的句读为准。
- 对确有底本差异的字句，以通行《周易正义》系经文为主，并用其余两处来源复核；不根据现代译文反推原文。
- 原文与下方“白话”严格分层。白话全部为本项目根据经文语境重新撰写，不复制任何现代译本。

## 白话边界

白话只解释经文呈现的处境、行动条件与风险，不把单卦静态写成“爱情吉”“事业凶”等现代分类，也不用“保证”“必然”“一定成功”“一定失败”等确定性措辞。实际问卦仍须结合起卦方式、动爻、纳甲、世应、六亲与日月等动态信息判断。
